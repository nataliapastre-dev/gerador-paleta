Um gerador interativo de paletas criado com HTML, CSS e JavaScript.  
Com ele você pode criar paletas aleatórias, copiar as cores com um clique e salvar suas paletas favoritas!

🔗 **Acesse o projeto online:**  
👉 [Clique aqui para abrir o Gerador de Paletas](https://nataliapastre-dev.github.io/gerador-paleta/)

---

## ✨ Funcionalidades

- ✔️ Gera paletas aleatórias com 5 cores  
- ✔️ Copia o código hexadecimal ao clicar em qualquer cor  
- ✔️ Copiar paleta completa com 1 clique  
- ✔️ Salvar paletas favoritas  
- ✔️ Interface moderna com gradiente  
- ✔️ Totalmente responsivo (PC e celular)

---

## 🚀 Tecnologias Utilizadas

- **HTML5**  
- **CSS3**  
- **JavaScript (ES6+)**

---

```bash
# Clonar o repositório
git clone https://github.com/natipastre/gerador-paleta.git

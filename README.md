Um gerador moderno e interativo de paletas de cores desenvolvido em **React**, com interface responsiva e funcionalidades práticas para designers e devs.  
Permite criar paletas aleatórias, copiar cores com um clique e salvar paletas favoritas de forma simples e rápida.

🔗 **Acesse o projeto online:**  
👉 [Clique aqui para abrir o Gerador de Paletas](https://nataliapastre-dev.github.io/gerador-paleta/)

---

## ✨ Funcionalidades

- 🎨 **Geração automática** de paletas com 5 cores  
- 📋 **Copiar cor individual** ao clicar em qualquer card  
- 📦 **Copiar toda a paleta** de uma vez  
- 💾 **Salvar paletas favoritas**  
- 📱 **Layout totalmente responsivo** (mobile, tablet e desktop)  
- ✨ Interface moderna feita com gradientes e transições suaves  
- ⚛️ Aplicação organizada em componentes React  

---

## 🚀 Tecnologias Utilizadas

### **Frontend**
- **React.js**
- **Vite**
- **JavaScript (ES6+)**
- **HTML5**
- **CSS3**

### **Outros**
- Organização modular por componentes
- Hooks do React (useState, useEffect)
- Deploy via **GitHub Pages**

## 📦 Como Usar o Projeto Localmente

```bash
# Clonar o repositório
git clone https://github.com/natipastre/gerador-paleta.git

# Acessar a pasta do projeto
cd gerador-paleta

# Instalar dependências
npm install

# Executar o projeto em ambiente de desenvolvimento
npm run dev

# Gerar build de produção
npm run build
